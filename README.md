# 고척초등학교 기버데이 인생네컷 포토부스

웹캠으로 사진 2컷을 찍어 4×6인치 용지에 인쇄하는 앱입니다. 용지를 세로로 반으로 자르면 두 사람이 똑같은 2컷을 나눠 가집니다.

파일은 `index.html` 하나이고, 글씨체는 `fonts/` 폴더에 들어 있습니다. 두 가지를 항상 같은 폴더에 두세요.

## 사용 순서

1. 앱을 열고 카메라 사용을 **허용**합니다.
2. **배경 미리보기** → 테마(기버데이 / 우주 / 동물 / 하트)를 누릅니다.
   - 처음 누르는 테마는 **프레임 사진**을 고르는 창이 열립니다. 한 번 고르면 이 브라우저에 저장되어 계속 사용합니다.
   - 사진을 바꾸려면 **이 테마 프레임 바꾸기**, 지우려면 **프레임 지우기**를 누릅니다.
3. **촬영 시작**(또는 스페이스 키) → 5초 카운트다운 후 2번 찍습니다.
4. **바로 인쇄**를 누르면 곧바로 처음 화면으로 돌아가고, 인쇄가 끝나면 찍은 사진은 화면에서 지워집니다.

## 프레임 사진 규격

- 크기는 **1200 × 1800 픽셀(가로:세로 = 2:3)** 로 만들어 주세요. 다르면 화면에 경고가 뜹니다.
- 사진 칸은 프레임에 따로 만들 필요가 없습니다. 앱이 프레임 위에 사진을 올려 줍니다.
- 사진이 올라가는 자리(1200×1800 기준, 왼쪽 위 모서리 좌표)

  | | 왼쪽 | 오른쪽 |
  |---|---|---|
  | 윗줄 | x 57.5, y 90 | x 657.5, y 90 |
  | 아랫줄 | x 57.5, y 785 | x 657.5, y 785 |

  사진 한 장의 크기는 485 × 655 입니다. 가운데(x 600)로 자르면 양쪽 여백이 같아집니다.
- 하단 문구 3줄(고척초등학교 / ♥기버데이♥ / 2026.11.19)은 두 사진 아래 y 1550~1710 쯤에 들어갑니다. 이 자리를 비워 두면 글씨가 잘 보입니다.

## 창 없이 바로 인쇄하기 (크롬)

크롬을 처음 켤 때 `--kiosk-printing` 옵션을 붙이면 인쇄 창 없이 바로 인쇄됩니다.

1. 열려 있는 크롬 창을 **모두 닫습니다.**
2. `start-photobooth.bat` 파일을 메모장으로 열어 `URL=` 뒤의 주소를 실제 앱 주소로 바꿉니다.
3. 이 파일을 더블클릭해서 앱을 엽니다.

옵션 없이 열면 인쇄 창이 한 번 떠서 직접 눌러야 합니다. 기본 프린터와 용지(4×6)는 윈도우에서 미리 맞춰 두세요.

## 글씨체

- `fonts/KOTRAHOPE.woff2` : 코트라 희망체 (화면과 인쇄물 글씨)
- `fonts/Cafe24Supermagic-Bold.woff2` : 카페24 슈퍼매직체

미리보기 팝업의 **✏️ 글씨체** 버튼에서 하단 문구(고척초등학교 / ♥기버데이♥ / 날짜)의 글씨체를 고릅니다. 고른 글씨체는 기억됩니다.

## 개인정보

- 찍은 사진은 인쇄가 끝나면 화면에서 지워집니다. 파일로 저장하는 기능은 없습니다.
- 프레임 사진은 이 컴퓨터의 브라우저 안에만 저장됩니다.

## 설정값 위치 (`index.html` 위쪽 `CONFIG`)

| 이름 | 뜻 |
|---|---|
| `photoWidth`, `photoHeight` | 사진 한 장 크기 |
| `marginLeft`, `marginTop`, `gapY` | 사진 위치와 간격 |
| `countdownSec` | 카운트다운 초 |
