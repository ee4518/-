# 고척초등학교 기버데이 인생네컷 포토부스

웹캠으로 사진 2컷을 찍어 4×6인치 용지에 인쇄하는 앱입니다. 용지를 세로로 반으로 자르면 두 사람이 똑같은 2컷을 나눠 가집니다.

파일은 `index.html` 하나이고, 글씨체는 `fonts/` 폴더에 들어 있습니다. 두 가지를 항상 같은 폴더에 두세요.

## 사용 순서

1. 앱을 열고 카메라 사용을 **허용**합니다.
2. **배경 미리보기** → 테마(기버데이 / 우주 / 동물 / 하트)를 누르면 그 테마의 프레임이 바로 적용됩니다.
3. **촬영 시작**(또는 스페이스 키) → 5초 카운트다운 후 2번 찍습니다.
4. 미리보기 팝업 아래에서 **🖨️ 인쇄 장수**(1~5장)를 고릅니다. 기본은 1장이고, 인쇄하고 나면 다시 1장으로 돌아갑니다. (종이 한 장을 반으로 잘라 두 명이 나눠 갖습니다.)
5. **바로 인쇄**를 누르면 곧바로 처음 화면으로 돌아가고, 인쇄가 끝나면 찍은 사진은 화면에서 지워집니다.

## 카메라가 없거나 안 될 때

- 카메라가 연결되지 않아도 안내 문구 없이 **까만 화면**이 나오고, 그대로 `촬영 시작`을 눌러 촬영 → 미리보기 → 인쇄 과정을 시험할 수 있습니다. 찍힌 사진도 까맣게 나옵니다.
- 나중에 카메라를 꽂으면 저절로 다시 연결됩니다. 연결이 안 되면 새로고침해 보세요.
- 인쇄 버튼과 인쇄 장수는 **사진을 찍은 뒤에만** 나타납니다. 촬영 전에 **배경 미리보기**를 누르면 배경만 볼 수 있고 인쇄 버튼은 없습니다.

## 프레임 사진

프레임은 `frames/` 폴더의 파일을 자동으로 씁니다. 파일 이름이 테마입니다.

| 테마 | 파일 |
|---|---|
| 🎁 기버데이 | `frames/school.webp` |
| 🚀 우주 | `frames/space.webp` |
| 🐾 동물 | `frames/animals.webp` |
| 💖 하트 | `frames/heart.webp` |

- 프레임을 바꾸려면 **같은 이름으로 파일만 덮어쓰면** 됩니다. (PNG를 쓰려면 `index.html` 의 `FRAME_FILES` 에서 파일 이름을 바꾸세요.)
- 크기는 **1200 × 1800 픽셀(가로:세로 = 2:3)** 입니다.
- 파일이 없거나 안 열리면 코드로 그린 기본 그림이 대신 나옵니다.
- 사진이 올라가는 자리(1200×1800 기준, 왼쪽 위 모서리 좌표)

  | | 왼쪽 | 오른쪽 |
  |---|---|---|
  | 윗줄 | x 57.5, y 90 | x 657.5, y 90 |
  | 아랫줄 | x 57.5, y 785 | x 657.5, y 785 |

  사진 한 장의 크기는 485 × 655 입니다. 가운데(x 600)로 자르면 양쪽 여백이 같아집니다.
- 하단 문구 3줄은 두 사진 아래 y 1550~1710 쯤에 들어갑니다. 프레임의 이 자리를 비워 두면 글씨가 잘 보입니다.
- 앱은 파일이 아니라 **웹 주소로** 열어야 프레임 사진이 나오고 인쇄가 됩니다.

## 가로 사진 (6×4)

- **촬영 시작** 버튼 옆의 `▯ 세로` / `▭ 가로` 로 고릅니다. 촬영 중에는 바꿀 수 없고, 방향을 바꾸면 이전에 찍은 사진은 지워집니다.
- 가로를 고르면 촬영 화면과 미리보기가 가로 모양으로 바뀝니다.
- 종이는 위아래로 반으로 잘라 두 명이 나눠 갖습니다. 반쪽마다 사진 2장(655×485)과 오른쪽에 문구 3줄이 들어갑니다.
- 프린터에는 용지를 세로로만 넣기 때문에, 가로 사진은 90도 돌려서 세로 용지(4×6)에 인쇄합니다. 인쇄된 종이는 옆으로 눕혀서 보면 정상으로 보입니다.
- 가로 프레임은 `frames/` 폴더에 아래 이름으로 넣으면 자동으로 쓰입니다. 크기는 **1800 × 1200 픽셀(3:2)** 입니다. 없으면 테마 색의 단순한 배경이 나옵니다.

  | 테마 | 파일 |
  |---|---|
  | 🎁 기버데이 | `frames/school_landscape.webp` |
  | 🚀 우주 | `frames/space_landscape.webp` |
  | 🐾 동물 | `frames/animals_landscape.webp` |
  | 💖 하트 | `frames/heart_landscape.webp` |

- 가로 사진이 올라가는 자리(1800×1200 기준, 왼쪽 위 모서리 좌표)

  | | 왼쪽 사진 | 오른쪽 사진 |
  |---|---|---|
  | 위쪽 반 | x 57.5, y 57.5 | x 752.5, y 57.5 |
  | 아래쪽 반 | x 57.5, y 657.5 | x 752.5, y 657.5 |

  문구는 사진 오른쪽(x 1447~1742)에 반쪽마다 한 번씩 들어갑니다.

## 창 없이 바로 인쇄하기 (크롬)

크롬을 처음 켤 때 `--kiosk-printing` 옵션을 붙이면 인쇄 창 없이 바로 인쇄됩니다.

1. 열려 있는 크롬 창을 **모두 닫습니다.**
2. `start-photobooth.bat` 파일을 메모장으로 열어 `URL=` 뒤의 주소를 실제 앱 주소로 바꿉니다.
3. 이 파일을 더블클릭해서 앱을 엽니다.

옵션 없이 열면 인쇄 창이 한 번 떠서 직접 눌러야 합니다. 기본 프린터와 용지(4×6)는 윈도우에서 미리 맞춰 두세요.

### 인쇄 크기 (프린터가 큰 용지로 인식할 때)

- 인쇄 용지 크기는 프린터가 정한 값을 그대로 쓰고(`@page size: auto`), 사진은 항상 종이의 **왼쪽 위 모서리에 100×148mm(엽서 크기)** 로 놓습니다. 윈도우가 프린터를 Letter/A4 용지로 인식해도 인화지에 사진이 맞게 찍히게 하기 위한 것입니다.
- 크기를 바꾸려면 `index.html` 위쪽 `--print-w`, `--print-h` 값을 바꿉니다.
- 색이 흑백으로 나오는 것은 앱이 아니라 프린터 드라이버 설정(단색만 가능하다고 인식) 때문입니다. 프린터 펌웨어 업데이트나 인쇄 기본 설정에서 컬러를 선택할 수 있어야 합니다.

## 글씨체

화면의 모든 글씨와 인쇄물 글씨는 **카페24 슈퍼매직체**입니다. 글씨체 파일은 `fonts/Cafe24Supermagic-Bold.woff2` 이고, 인터넷이 없어도 이 파일로 나옵니다.

## 개인정보

- 찍은 사진은 인쇄가 끝나면 화면에서 지워집니다. 파일로 저장하는 기능은 없습니다.

## 설정값 위치 (`index.html` 위쪽 `CONFIG`)

| 이름 | 뜻 |
|---|---|
| `photoWidth`, `photoHeight` | 사진 한 장 크기 |
| `marginLeft`, `marginTop`, `gapY` | 사진 위치와 간격 |
| `countdownSec` | 카운트다운 초 |
